# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) and adheres to [Semantic Versioning](https://semver.org/).

## [1.2.0] - 2026-08-20
### Added
- Rich-text block editor powered by TipTap v3.
- Table and code syntax highlighting in task descriptions.
- Enhanced export options (PDF, Excel, JSON).

### Fixed
- Resolved layout flickering during column drag-and-drop on mobile touch screens.
- Fixed token refresh race condition when multiple tabs wake from sleep.

## [1.1.0] - 2026-07-28
### Added
- Real-time Socket.io workspace presence indicators.
- Workspace member invitation flow with role management.

## [1.0.0] - 2026-07-01
### Initial Release
- Core Kanban board with swimlanes.
- Authentication with JWT and cookie support.
